# Content Corpus

This folder contains Markdown source material for Nihiltheism, nihilism, definitions, memory notes, drafts, and related philosophical research.

The corpus is separated from `src/` so research material is not confused with application code.

## Structure

- `definitions/source-notes/` - definition drafts, glossary material, summaries, and conceptual fragments.
- `nihilism/source-notes/` - Nihilism/REN drafts, edits, works, memory notes, and related source material.

## Rules

- Keep source material here unless it becomes app runtime data.
- Do not delete historical drafts during cleanup; archive or classify them first.
- Prefer adding index files and metadata over flattening the source corpus.
- If a file becomes canonical app content, document that promotion in `docs/operations/`.
